# 배포본 만드는 법 (쉬운 설명서)

> MD좋아 설치파일을 만들어 사내에 나눠주는 방법이에요. 어려운 말 없이 순서대로 적었어요.

## 먼저 알아둘 한 가지
프로그램은 **만드는 컴퓨터 종류대로** 나와요.
- **맥에서 만들면 → 맥용**(.dmg)
- **윈도우에서 만들면 → 윈도우용**(.exe)

한 컴퓨터에서 둘 다는 못 만들어요. 그래서 **맥 한 대, 윈도우 한 대**에서 각각 한 번씩 만들면 돼요.

---

## 🍎 맥용 만들기 (지금 쓰는 맥에서)
1. 터미널을 열고 프로젝트 폴더로 가요.
2. 아래 **한 줄**을 입력해요:
   ```bash
   npm run release
   ```
3. 몇 분 기다리면 "다 됐어요!" 메시지와 함께 파일 위치를 알려줘요.
4. 설치파일은 여기 있어요:
   ```
   src-tauri/target/release/bundle/dmg/MD좋아_<버전>_aarch64.dmg
   ```
5. 이 `.dmg` 파일을 사내에 올리면 끝. (사람들은 더블클릭해서 설치)

### ⚠️ 맥에서 "손상되어 열 수 없습니다"가 뜰 때
앱에 **애플 서명·공증이 없어서**, 인터넷(다운로드/GitHub)으로 받은 `.dmg`는 macOS가
"손상됨"으로 막아요. **진짜 손상된 게 아니에요** — 격리 표시 때문이에요. 받은 사람이
터미널에 **한 줄**만 입력하면 풀려요:

```bash
# 받은 .dmg 격리 해제 (경로/버전은 실제 받은 파일로)
xattr -dr com.apple.quarantine ~/Downloads/MD좋아_<버전>_aarch64.dmg
```
그 뒤 dmg를 열고 앱을 **응용 프로그램**으로 옮긴 다음, 혹시 또 막히면 앱에도:
```bash
xattr -dr com.apple.quarantine /Applications/MD좋아.app
```
→ 이제 더블클릭으로 정상 실행돼요. (배포 메일/안내에 이 한 줄을 같이 적어두면 편해요.)

> 참고: 경고 없이 누구나 바로 열리게 하려면 **Apple 개발자 ID 서명 + 공증**(연 $99 계정)이
> 필요해요. 이 앱은 메인 타깃이 Windows이고 맥은 보조라, 사내 사용이면 위 `xattr` 안내로 충분.
> 로컬에서 직접 빌드한 `.dmg`는 다운로드가 아니라서 이 문제가 없어요(격리 표시 안 붙음).

## 🪟 윈도우용 만들기 (윈도우 PC에서)
> 윈도우 PC에서 **처음 한 번만** 준비물을 깔아야 해요. 그다음부터는 한 줄이면 돼요.

**처음 한 번만 준비 (둘 중 빠진 게 있으면 설치):**
- Node.js, Git
- Rust (rustup) + "Visual Studio Build Tools"의 C++ 구성 요소
- (Windows 11은 보통 WebView2가 이미 있음. Windows 10이면 없을 수 있는데, 설치 과정에서 자동으로 받아요.)

**만들기:**
1. 소스를 받아요 (이미 받았으면 생략):
   ```bash
   git clone <저장소 주소>
   cd mdjoa
   git checkout feat/windows-support   # 윈도우 작업 브랜치
   npm install
   ```
2. **한 줄** 입력:
   ```bash
   npm run release
   ```
3. 다 되면 설치파일은 여기 있어요:
   ```
   src-tauri\target\release\bundle\nsis\   ← .exe 설치파일
   ```
4. 이 `.exe`를 사내에 올리면 끝. (관리자 권한 없이 사용자별 설치돼요.)

> ⚠️ 윈도우용을 **정식 배포하기 전에** 해둘 일들이 따로 있어요(워드 변환에 필요한 검증번호 채우기, 실제로 켜서 테스트, 서명 등). 그건 `docs/windows-todo.md`에 쉬운 체크리스트로 적어놨어요.

## 🤖 인터넷 자동 만들기 (선택 — 컴퓨터 없이도)
GitHub에 올리면 인터넷(GitHub Actions)이 **맥용·윈도우용을 자동으로 둘 다** 만들어줘요.
- 코드를 올리면(push) 자동으로 시작돼요.
- 다 만들어진 파일은 GitHub의 "Actions" 화면에서 내려받아요.
- 즉, 윈도우 컴퓨터가 당장 없어도 윈도우용을 받을 수 있어요.

## ✅ 정리 (한눈에)
| 무엇 | 어디서 | 명령 | 결과물 위치 |
|---|---|---|---|
| 맥용 | 맥 | `npm run release` | `…/bundle/dmg/*.dmg` |
| 윈도우용 | 윈도우 PC | `npm run release` | `…\bundle\nsis\*.exe` |
| 둘 다 자동 | 인터넷(GitHub) | 코드 push | GitHub Actions에서 다운로드 |

버전 올릴 때: `package.json` / `src-tauri/Cargo.toml` / `src-tauri/tauri.conf.json` 세 곳의 버전 숫자를 똑같이 맞춰요.
