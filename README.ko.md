# MD좋아 (MDjoa)

> **AI가 문서를 쓰는 순간, 바로 읽을 수 있게.**
> AI 도구가 매일 만드는 Markdown 파일을 위한 가벼운 데스크톱 뷰어입니다.

🇺🇸 [English README](README.md)

---

## 왜 MD좋아인가?

AI와 일해 보셨다면 익숙한 장면일 거예요.

- Claude, Codex, Cursor가 계획, 명세, 요약, 메모를 `.md` 파일로 십수 개씩 써 냅니다.
- 메모장이나 VS Code로 열면 `#`, `**`, `|---|` 같은 기호가 그대로 보여서 문서처럼 읽히지 않습니다.
- AI가 파일을 고쳤는데 무엇이 바뀌었는지 모릅니다. 다시 열고, 스크롤하고, 차이를 찾아야 합니다.
- 파일을 복사해 채팅창에 붙여넣고, AI가 최신 버전을 보고 있기를 바랍니다.
- 파일이 열 개를 넘으면 필요한 결정이 어느 파일에 있었는지 기억나지 않습니다.

**MD좋아는 이 반복을 줄이려고 만들었습니다.** AI가 만든 Markdown을 실제로 읽을 수 있는 문서로 보여주고, AI가 작업하는 동안에도 내용을 최신 상태로 유지합니다.

- **기호 대신 문서로.** 표, 다이어그램, 코드 하이라이팅까지 깔끔한 페이지로 보여줍니다.
- **바뀌는 순간 확인.** 디스크의 파일이 바뀌면 화면이 바로 갱신됩니다. 다시 열 필요도, 새로고침할 필요도 없습니다.
- **AI가 바꾼 내용 검토.** 처음 열었을 때의 버전과 현재 버전을 비교할 수 있습니다.
- **여러 파일도 빠르게.** 단축키 한 번으로 문서를 열고, 폴더 전체를 검색하고, 보던 자리로 돌아갈 수 있습니다.
- **내 컴퓨터에서.** 모든 작업은 내 컴퓨터에서 이뤄지며, 계정이나 로그인이 필요 없습니다.

MD좋아는 편집기(IDE)가 아니라 뷰어입니다. 하나의 일에 집중합니다. 문서를 빠르고 정확하게 읽고 확인하게 돕는 것입니다.

## 이런 분께 맞습니다

- **개발자**: 프로젝트에서 AI 에이전트를 여러 개 돌리고, 결과물을 작업 흐름을 끊지 않고 검토하고 싶은 분.
- **비개발자**: 글쓰기, 리서치, 기획, 번역에 AI를 쓰고, Markdown 문서를 코드가 아닌 문서처럼 보고 싶은 분.
- **누구나**: 메모, 초안, AI 결과물이 담긴 폴더가 계속 커져서 필요한 문서를 빨리 찾아 읽어야 하는 분.

MD좋아를 쓰는 데 Markdown 문법, Git, 명령줄을 알 필요는 없습니다.

## 주요 기능

- **보기 좋게 읽기.** GitHub 방식 Markdown: 표, 각주, 체크박스, 콜아웃, 수식, Mermaid 다이어그램, 코드 하이라이팅. 읽던 위치를 기억합니다.
- **문서가 실시간으로 갱신.** AI 도구나 다른 편집기가 고친 파일은 자동으로 새로고침됩니다. 편집 중에는 작업 내용을 덮어쓰지 않도록 알려 줍니다.
- **AI 변경 검토.** 처음 열었던 버전과 나란히 비교합니다.
- **AI에 줄 맥락 준비.** 관련 문서를 모으고, 토큰 수를 확인하고, 다음 AI 세션에 붙여넣을 프롬프트로 복사합니다.
- **메뉴에서 AI 작업 실행.** 로컬 `claude` CLI로 문서를 검토, 개선, 요약, 번역합니다. 선택 기능이며 직접 클릭할 때만 실행됩니다.
- **빠른 이동.** 명령 팔레트(`Cmd/Ctrl+K`), 빠른 열기(`Cmd/Ctrl+O`), 폴더 전체 검색, 뒤로/앞으로 이동, 여러 창.
- **파일 관리.** 파일 트리에서 이름 바꾸기와 삭제. 즐겨찾기와 최근 문서가 자동으로 맞춰집니다.
- **간단한 편집.** Markdown 원본을 분할 미리보기와 함께 편집하고 자동 저장합니다.
- **Markdown 밖의 파일도.** 텍스트 파일과 소스 코드 파일도 문법 색상과 함께 열립니다.
- **내 언어로.** 한국어와 영어 UI를 설정에서 바꿀 수 있고, 네이티브 메뉴와 창 제목까지 함께 바뀝니다.
- **문서로 내보내기.** PDF, Word, HTML로 내보냅니다. 집중 모드(`Cmd/Ctrl+Shift+Enter`)로 방해 없이 읽을 수 있습니다.

자세한 사용법: [한국어 매뉴얼](docs/user-manual.md) · [English](docs/user-manual.en.md)

## 설치

1. [GitHub Releases](https://github.com/ato22c/mdjoa/releases) 페이지를 엽니다.
2. 내 운영체제에 맞는 설치 파일을 받습니다.
   - Windows: `.exe` 설치 파일
   - macOS: `.dmg` 이미지
3. 설치 파일을 실행하고 안내에 따라 설치합니다.

**winget**: 준비 중입니다.

### 소스에서 직접 빌드

준비물: Node.js 20 이상, Rust(rustup), 각 OS의 빌드 도구(Windows는 C++ 워크로드가 포함된 Visual Studio Build Tools, macOS는 Xcode Command Line Tools).

```bash
npm install
npm run tauri dev     # 개발 모드(핫 리로드)
npm run release       # 현재 OS용 설치 파일 생성
```

설치 파일은 `src-tauri/target/release/bundle/`에 만들어집니다.

## 이슈 제보

버그는 [GitHub Issues](https://github.com/ato22c/mdjoa/issues)에 올려 주세요. 버그 제보 양식을 사용하면 되고, 다음 내용을 적어 주시면 큰 도움이 됩니다.

1. **앱 버전**: 햄버거 메뉴 → 정보(About)에서 확인.
2. **운영체제와 재현 방법**.
3. **진단 로그(선택, 있으면 도움이 됨)**:
   1. **설정**에서 **진단 로그 폴더 열기**를 클릭합니다(명령 팔레트에도 같은 명령이 있습니다).
   2. `mdjoa.log` 파일을 이슈에 첨부하거나, 관련 줄을 복사해 붙여넣습니다.
   3. **올리기 전에 꼭 확인해 주세요.** 로그에는 파일 경로가 들어 있을 수 있습니다. 공개하고 싶지 않은 폴더 이름이나 문서 제목 등은 지워 주세요.
