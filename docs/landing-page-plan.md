## 3. 솔루션 — 핵심 기능 4개

**소제목**: MD좋아는 "AI가 고친 문서 검토"만을 위해 만든 뷰어입니다.

1. **자동 새로고침** — 파일이 바뀌면 뷰어가 즉시 갱신. 새로고침 버튼 누를 필요 없음.
2. **AI 변경 리뷰 센터** — 처음 봤던 내용과 지금 디스크 내용을 좌우 diff로 바로 비교.
3. **한↔영 번역, 추가 과금 없음** — 이미 쓰고 계신 Claude 계정으로 즉시 번역.
4. **빠른 읽기** — 표·체크박스·Mermaid·수식·코드 하이라이팅까지 GFM 완전 렌더링, 커맨드 팔레트(`⌘/Ctrl+K`)로 어디서든 바로 이동.

**그 외에도**: 칸반 백로그 대시보드, PDF·HTML 파일 뷰어, PDF·Word 내보내기, 집중 모드, 문서 비교, 위키링크·백링크 — 한 줄로 나열, 상세 설명 생략(핵심 4개에 집중, 장식 금지 원칙).

## 4. 왜 MD좋아인가

- **Windows에서도 완전히 동일하게 작동합니다.** (경쟁 툴 이름은 언급하지 않되, "Mac 전용 아님"이라는 사실 자체로 차별화 — 세션 조사 결과 Nimbalyst·Marky·MD+HTML Reader 모두 Mac/영어권 우선)
- **한국어로 만들어졌습니다.** 메뉴·설정·번역까지 전부 한국어 우선.

## 8. FAQ (Notion toggle list)

- **VS Code로도 되는 거 아닌가요?** — 미리보기는 되지만, 자동 새로고침·diff 리뷰·번역은 안 됩니다. MD좋아는 그 워크플로 자체를 위해 만들었습니다.
- **Windows에서도 되나요?** — 네, Windows가 메인 타깃입니다. macOS도 동일하게 지원합니다.
- **번역이 무료라는 게 무슨 뜻인가요?** — 이미 쓰고 계신 로컬 `claude` CLI(Claude Code) 계정을 그대로 사용합니다. 별도 API 키·추가 결제 없습니다.
- **텔레메트리 있나요?** — 없습니다. 번역 기능을 쓸 때만 사용자가 직접 트리거해 Anthropic과 통신하고, 그 외엔 완전히 로컬입니다.
- **결제하면 정확히 뭘 받나요?** — 최신 버전(v1.5.0) 다운로드 링크(Windows/macOS)입니다.
- **환불되나요?** — Gumroad 정책에 따름 (게시 전 Gumroad 환불 정책 확인 필요 — Open Question).
