# MD좋아 — AI 개발자용 기능 제안

> 작성: 2026-06-13 · 대상 사용자: **agentic AI 개발자**
> 업데이트: 2026-06-14 — **작업 현황 반영**. 상태 표기: ✅ 완료 · 🔧 진행 중 · ⬜ 미착수 · ⏸ 보류
> 후속 심화 기획 및 추가 완료 항목은 [`ai-dev-features-v2.md`](./ai-dev-features-v2.md) 참조.

## 1. 제품 목적

요즘 **agentic AI 개발**은 개발자가 수많은 Markdown 문서를 다룬다 —
`CLAUDE.md` / `AGENTS.md`, skill `SKILL.md`, 프롬프트 템플릿, 설계 문서,
태스크 목록, eval 리포트 등. **MD좋아**는 그 AI 개발자를 위한 **경량 MD 뷰어**다.

핵심 니즈 세 가지:

1. MD 문서를 **잘 읽기**
2. 자주 확인하는 MD를 **쉽게 열기**
3. **AI가 수정한 MD를 즉시 갱신**해서 확인하기

> 설계 원칙은 그대로 유지: *콘텐츠 퍼스트 미니멀 · 경량 · 기능 과잉 금지.*
> 아래 제안도 "AI 개발 워크플로에 직접 기여하는가 + UI 크롬을 안 늘리는가"로 선별.

## 2. 현재 커버 현황

| 니즈 | 현재 기능 |
| --- | --- |
| 읽기 | 렌더링, 목차(스크롤 스파이), 다크/라이트, 코드 하이라이팅, Mermaid |
| 쉽게 열기 | 즐겨찾기(별·경로표시·DnD 순서·높이조절), 최근(폴더 포함), 세션 복원, 탐색기 트리 |
| 즉시 갱신 | 파일 워처 자동 새로고침 + `↻ 업데이트됨` 뱃지 / 수동 모드 / 삭제 감지 |
| 기타 | 내보내기(PDF/DOCX/HTML), 웹링크 외부 열기, Finder에서 보기, 검색(문서 내) |

→ 기본은 충분히 갖춤. 다음은 **AI 개발 특화 차별화**를 얹는 단계.

## 3. 제안 (Notion / Obsidian 벤치마크)

### Tier 1 — 강력 추천 (AI-dev 차별화, 미니멀 유지) → **전부 ✅ 완료**

1. **변경 하이라이트** ⭐ _가장 차별적_ — ✅ 완료 (`lib/textDiff.ts` + 자동 새로고침 줄 강조)
   - 자동 새로고침 시 **바뀐 줄을 잠깐 강조**(추가/삭제 표시) → "AI가 뭘 바꿨는지" 즉시 인지.
   - 벤치마크: Notion 페이지 히스토리의 경량판 / git diff 감성. (이미 만든 auto-reload 위에 얹음)

2. **Quick Open 파일 스위처 (⌘P)** — ✅ 완료 (`components/screens/QuickOpen.tsx`)
   - 열린 폴더의 모든 MD를 **퍼지 검색으로 즉시 전환**. 많은 파일을 오갈 때 필수.
   - 벤치마크: Obsidian Quick Switcher / VS Code `⌘P`.

3. **폴더 전체 Full-text 검색** — ✅ 완료 (`FolderSearch.tsx` + Rust `search_in_folder`, 깊은 폴더 검증 완료)
   - 현재는 문서 내 검색만 → **폴더 전체 내용 검색**, 파일+위치로 점프.
   - 벤치마크: Obsidian 글로벌 검색.

4. **토큰 카운트** — ✅ 완료 (`lib/tokenizer.ts` 정확 BPE + TopBar 표시)
   - 문서(및 선택 영역)의 **토큰 / 단어 / 문자 수**. 프롬프트·컨텍스트 문서 작성 시 필수.
   - 벤치마크: Notion 단어 수 + **AI-dev 특화(토큰)**.

5. **YAML Frontmatter 메타 렌더** — ✅ 완료 (`markdown.ts:extractFrontmatter`, `.md-frontmatter` 카드)
   - skill/agent 파일의 `--- name / description ---` 블록을 raw 대신 **깔끔한 메타 카드**로.
   - 벤치마크: Obsidian Properties.

6. **폴더 변경 피드 + 트리 뱃지** — ✅ 완료 (`useFolderWatch` + `changedFiles` 뱃지)
   - AI 에이전트가 **여러 파일을 동시에 수정**할 때, 트리/패널에 "방금 바뀐 MD" 표시.
   - 벤치마크: Notion 업데이트 피드.

### Tier 2 — 가치 있음 (Obsidian / Notion 벤치마크)

7. **위키링크 `[[파일]]` + 백링크** — ✅ 완료 (`BacklinksPanel.tsx`, 위키링크 룰). 문서 간 이동 + "이 문서를 참조하는 문서". (Obsidian 코어)
8. **인터랙티브 체크박스** — ✅ 완료 (`toggleTask` + Rust `toggle_task`). 렌더 화면에서 체크박스 클릭 → 파일에 반영. (Obsidian/Notion)
9. **탭 (멀티 문서)** — ⏸ **누적형 멀티탭 드롭**. 대신 ✅ 뒤로/앞으로 히스토리 + ✅ 얇은 멀티윈도우("새 창에서 열기") + ✅ 온디맨드 비교로 대체(2026-06-14, `multi-document-strategy.md` 업데이트 참조).
10. **Callout / Admonition** — ✅ 완료 (`CALLOUT_TYPES`). `> [!note]` 강조 블록 렌더. (Obsidian)

### Tier 3 — 더 무겁거나 선택적

- 로컬 **스냅샷 히스토리** (버전 비교/되돌리기) — ⏸ 보류 (비권장, v2 §H — git이 1급 도구이므로 자체 저장소 미도입)
- 두 파일 **side-by-side diff** (예: 프롬프트 v1 vs v2) — ⬜ 미착수 (v2 §B에서 **유니파이드 1컬럼**으로 재기획, 미구현)
- **워크스페이스** (관련 MD 세트 저장·일괄 열기) — ⬜ 미착수 (#1 멀티탭 안정화 선행)

### 제외 권장

그래프 뷰 · 플러그인 생태계 · 데이터베이스/임베드 등 무거운 기능 →
"경량 뷰어" 정체성과 충돌하므로 제외.

## 4. 추천 로드맵 → **1차 로드맵 4종 전부 완료**

미니멀을 유지하면서 핵심 니즈를 가장 직접 충족하는 순서:

1. 변경 하이라이트 — ✅
2. Quick Open (⌘P) — ✅
3. 폴더 전체 검색 — ✅
4. 토큰 카운트 — ✅

이 4개가 "많은 MD를 다루고 + AI 수정을 추적"하는 니즈를 거의 크롬 증가 없이 충족한다.
**1차 제안은 사실상 완수**했고, 이후 단계는 `ai-dev-features-v2.md`(C/D/E/F 완료, A/B/G 미착수)에서 추적한다.

## 5. 기능 무게 평가 (경량성 검토)

> 핵심 정체성은 **경량 뷰어**. 아래 무게(구현 복잡도 + 런타임 비용)를 기준으로 선별.

| 기능 | 무게 | 이유 / 경량화 방법 |
| --- | :---: | --- |
| ① 변경 하이라이트 | 🟢 가벼움 | MD 한 문서의 텍스트 diff(LCS)만. 문서가 작아 빠름 |
| ② Quick Open(⌘P) | 🟢 가벼움 | 파일명 목록 + JS 퍼지 필터. 단, 수천 개 폴더는 초기 스캔 → 목록 캐시로 해결 |
| ⑤ Frontmatter 렌더 | 🟢 가벼움 | 작은 YAML 파싱 + 렌더 |
| ⑩ Callout 렌더 | 🟢 가벼움 | markdown-it 렌더러 추가 |
| ④ 토큰 카운트 | 🟡 근사=가벼움 / 정확=중간 | 정확 토큰=BPE 토크나이저(수 MB). **문자/4 근사** 권장 |
| ⑥ 폴더 변경 피드/뱃지 | 🟡 중간 | 폴더 재귀 감시 = watch 핸들·이벤트 폭증. 디바운스+스코프 필요 |
| ⑧ 인터랙티브 체크박스 | 🟡 중간(난이도) | 런타임 가벼움. 렌더 체크박스→원본 줄 매핑이 까다로움 |
| ⑨ 탭(멀티 문서) | 🟡 중간 | 여러 문서 메모리 상주 + 상태관리 |
| ③ 폴더 full-text 검색 | 🟠 중간~무거움 | 모든 MD 내용 스캔. 영구 인덱스는 무거움 → **온디맨드 스캔** 권장 |
| ⑦ 위키링크+백링크 | 🟠 링크=가벼움 / 백링크=중간~무거움 | 백링크는 전 파일 스캔/인덱스 필요 |
| 스냅샷 히스토리(T3) | 🔴 무거움 | 버전 디스크 저장+관리+UI |
| 그래프뷰·플러그인·DB(제외) | 🔴 매우 무거움 | 경량 정체성과 충돌 → 제외 |

### 무거운 것의 공통점

*여러 파일을 동시에 훑거나 인덱스를 유지*하는 기능 — **③ 폴더 검색 · ⑦ 백링크 · ⑥ 폴더 감시**.

### 경량화 처방

- **③ 폴더 검색** → 영구 인덱스 대신 **온디맨드 스캔**(Rust 백엔드 스트리밍), 결과 상한·취소 지원
- **⑦ 위키링크** → 우선 **이동만**(가벼움) 구현, 백링크는 나중에/옵션
- **⑥ 폴더 감시** → **현재 폴더 1단계만** 또는 열린 파일 주변만 + 디바운스
- **④ 토큰** → **근사값**으로 시작(정확 토크나이저는 옵션)

### 결론

- **확실히 가볍고 체감 큰 것부터**: ① 변경 하이라이트 · ② Quick Open · ⑤ Frontmatter · ⑩ Callout
- ③·⑦·⑥은 **경량 버전으로 범위를 좁혀** 도입
- 🔴 항목(스냅샷·그래프뷰·플러그인·DB)은 경량 정체성상 제외/보류
