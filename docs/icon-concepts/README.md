# MD좋아 앱 아이콘 시안 5종

**보는 법:** `docs/icon-concepts/index.html`을 브라우저로 열면 5종을 라이트/다크 배경 + 64·32·20px 축소(Dock·작업표시줄 가독성)로 한눈에 비교할 수 있습니다. 개별 파일은 아래 SVG.

| # | 시안 | 파일 | 한 줄 컨셉 |
|---|---|---|---|
| 1 | 마크다운 마크 (M↓) | `concept-1-markdown-mark.svg` | 종이 배경 + 잉크 M + 포인트 다운애로우. "Markdown 도구"가 즉시 읽힘. 가장 보편·안전 |
| 2 | 문서 + 좋아(하트) | `concept-2-page-heart.svg` | "좋아" 감성. 포인트 배경 문서+하트. 친근·따뜻. 요소 많아 초소형 디테일 주의 |
| 3 | md 모노그램 | `concept-3-md-monogram.svg` | 다크 배경 소문자 md 워드마크 + 마크다운 닷. 개발자 도구 톤. 초소형 가독 우수 |
| 4 | 콘텐츠 라인 | `concept-4-content-lines.svg` | 제목 한 줄(포인트)+본문. "본문이 주인공" 원칙 그 자체. 차분·고급. MD 인지는 약함 |
| 5 | 변경 하이라이트 | `concept-5-change-highlight.svg` | 한 줄만 강조된 문서. "AI가 바꾼 줄을 즉시 본다"는 제품 차별점 형상화. 스토리 강함 |

## 추천

- **정체성 정렬·고급감 우선** → **시안 4 (콘텐츠 라인)**: "콘텐츠 퍼스트 미니멀" 원칙과 정확히 일치. 단, 마켓에서 "Markdown"임을 한눈에 알리는 힘은 약함.
- **인지도·범용성 우선** → **시안 1 (마크다운 마크)**: 마크다운 정체성이 가장 직설적이고 모든 크기에서 안전.
- **차별화 스토리 우선** → **시안 5 (변경 하이라이트)**: 우리 제품의 AI-dev 차별점을 담음.

> 개인적으로는 **1과 4의 하이브리드**(종이 배경 + M↓를 살짝 얇게 + 상단에 포인트 제목 줄 한 개)도 강력 후보입니다. 원하시면 선택하신 시안을 다듬어 실제 아이콘 세트(`.png`/`.icns`/`.ico`)로 내보내고 `tauri.conf.json` 아이콘 경로에 반영하겠습니다.

## 다음 단계 (확정 후)

1. 한 시안 선택(또는 수정 요청).
2. 1024px PNG 마스터 → `icons/` 의 32/128/128@2x/icon.icns/icon.ico 일괄 생성(`tauri icon` 또는 수동).
3. macOS/Windows 빌드에서 Dock·작업표시줄·인스톨러 표시 확인.
