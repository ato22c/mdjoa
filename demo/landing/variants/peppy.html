## 자동 새로고침

AI가 파일을 고치면
화면이 먼저 압니다

에이전트가 .md를 고치면 화면이 알아서 다시 그려져요. 새로고침 버튼 누를 일이 없어요.

  • 파일이 바뀌면 바로 다시 그림
  • 편집 중일 땐 덮어쓰지 않고 알려만 줌
  • 새로 생기거나 바뀐 파일은 트리에 배지로

## AI 변경 리뷰 센터

뭐가 바뀌었는지
한 줄씩 확인

  • 이전과 현재를 좌우로 나란히
  • 새로 만든 파일, 고친 파일, 지운 파일 한눈에
  • 원본은 절대 건드리지 않음

## 한↔영 번역, 돈 더 안 듭니다

쓰던 계정 그대로,
번역까지

쓰고 계신 claude CLI를 그대로 씁니다. API 키를 새로 만들 필요도, 돈을 더 낼 일도 없어요. 원문과 번역을 나란히 놓고 복사하거나 저장하면 끝이에요.

  • 어느 쪽으로 번역할지 직접 선택 (한국어로 / 영어로)
  • 원문과 번역을 좌우로, 스크롤도 같이 움직임
  • 번역 버튼 누를 때만 통신
