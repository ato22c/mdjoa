# 배포 스킬 (deploy-web)

프로덕션 배포를 한 번에 처리하는 스킬. 사람이 매번 순서를 외울 필요 없이,
아래 절차를 그대로 따르면 됩니다.

> [!important] 배포 전 필수 확인
> `main` 브랜치가 최신인지, 테스트가 전부 통과했는지 먼저 확인하세요.
> 실패한 테스트가 하나라도 있으면 배포하지 않습니다.

## 언제 쓰나

- 사용자가 "배포", "deploy", "릴리스", "올려줘"라고 할 때
- PR 머지 직후 프로덕션 반영이 필요할 때

## 절차

1. 최신 코드 받기 + 테스트
   - [x] `git pull` 후 충돌 없음
   - [x] `npm test` 전부 통과
   - [ ] 스테이징에서 스모크 테스트
2. 빌드 → 배포 → 상태 확인

## 환경

| 환경 | 브랜치 | 자동 배포 | 롤백 |
| :--- | :--- | :---: | :---: |
| staging | `develop` | 예 | 자동 |
| production | `main` | 태그 푸시 시 | 수동 승인 |

## 명령

```bash
npm run build          # 프로덕션 번들
npm run deploy -- --prod
npm run canary         # 배포 후 5분 모니터링
```

배포가 끝나면 `#deploy` 채널에 자동으로 알림이 올라갑니다.
