# MD좋아 사용자 매뉴얼

이 매뉴얼은 MD좋아로 직접 열어 보면 콜아웃·목차·체크박스가 그대로 보입니다.

> [!tip] 이 문서를 MD좋아로 열어 보세요
> 도움말 메뉴 → **사용자 매뉴얼**을 누르면 바로 이 문서가 열립니다.

---

## 1. MD좋아란?

MD좋아는 Markdown(`.md`) 문서를 **빠르게 열어 읽는** 가벼운 뷰어입니다. `.html`·`.pdf` 파일도 렌더된 화면으로 바로 열 수 있습니다.
특히 AI 도구가 고쳐 놓은 문서를 즉시 다시 읽거나, 여러 문서를 빠르게 오가며 보는 데
편리합니다. 로그인이 필요 없고, 데이터를 밖으로 보내지 않습니다(모두 내 컴퓨터에서 처리).

**Windows 10/11**을 기본으로 지원하며, macOS에서도 동일하게 동작합니다. 단축키는
`Ctrl` 기반으로 표기하며(macOS는 `Ctrl` 대신 `⌘`), 맨 끝 [8. 단축키](#8-단축키)에 한 번에 모았습니다.

---

## 2. 빠른 시작

문서를 여는 방법은 여러 가지입니다. 편한 것을 쓰면 됩니다.

- 시작 화면의 **파일 열기** / **폴더 열기** 버튼
- 좌측 상단 **햄버거 메뉴(☰)** → 파일/폴더 열기
- **파일을 창 안으로 끌어다 놓기**(드래그 앤 드롭)
- 탐색기에서 `.md`·`.html` 파일 더블클릭(MD좋아를 기본 앱으로 지정한 경우)
- **새 문서 만들기**: `Ctrl+N` 또는 햄버거 메뉴 → **새 문서**. 위치·이름을 묻지 않고 **이름 없는 문서로 바로 편집**이 시작되며(입력 중에는 임시로 자동저장), **저장(`Ctrl+S`)하거나 다른 문서로 넘어갈 때** 파일명·위치를 정하는 창이 뜹니다. 파일 트리에서 폴더를 우클릭 → **이 폴더에 새 문서**로 그 폴더에 즉시(이름 자동) 만들 수도 있습니다.

> [!tip] 폴더를 열면 더 편합니다
> 파일 하나만 열 수도 있지만, **폴더를 열면** 왼쪽에 파일 목록(트리)이 생겨
> 문서 사이를 빠르게 오갈 수 있습니다.

앱을 껐다 켜면 **마지막에 보던 폴더와 파일이 자동으로 다시 열립니다**(세션 복원).

문서를 여러 개 오갈 때는 **뒤로/앞으로**(`Ctrl+[` `Ctrl+]` 또는 `Ctrl+←` `Ctrl+→`, 상단 바의 **← →** 버튼)로 브라우저처럼 이동할 수 있습니다. 또 트리·빠른 열기·햄버거의 **새 창에서 열기**로 문서를 **독립 창**에 띄워 두 문서를 나란히 볼 수도 있습니다.

> [!tip] 무엇이든 `Ctrl+K` 한 번으로 — 명령 팔레트
> `Ctrl+K`(macOS는 `⌘K`)를 누르면 **명령 팔레트**가 열립니다. 파일 열기·새 문서·비교·
> 검색·테마·집중 모드·변경 리뷰 등 **거의 모든 기능을 이름으로 검색해 바로 실행**할 수 있어,
> 메뉴나 버튼 위치를 외우지 않아도 됩니다. (`↑`/`↓` 이동, `Enter` 실행, `Esc` 닫기)

## 3. 문서 읽기

MD좋아는 GitHub 스타일(GFM) Markdown을 보기 좋게 렌더링합니다. 표, 각주, 코드 블록
(구문 강조 + 우상단 **복사** 버튼), 이미지, 콜아웃(`> [!note]` 등), 체크박스, 문서 맨 앞의
메타데이터(`--- … ---`)를 그대로 지원합니다. 여기서는 이 앱에서만 쓸 수 있는 유용한
기능들을 소개합니다.

> [!note] 안전을 위해 HTML 태그는 표시하지 않습니다
> Markdown 문서 안에 직접 쓴 원시 HTML은 그려지지 않습니다. 순수 Markdown 문법으로 작성하세요.

### HTML · PDF 파일 보기

`.html`/`.htm` 파일은 **브라우저처럼 렌더된 화면**으로 열립니다(소스 코드가 아님). `.pdf` 파일은
OS 내장 PDF 뷰어로 표시됩니다(Windows=WebView2, macOS=WKWebView). 파일 열기 다이얼로그·
드래그앤드롭·파일 트리 어디서나 열 수 있습니다.

> [!note] HTML·PDF는 편집·AI 작업·내보내기를 지원하지 않습니다
> 텍스트 Markdown이 아닌 파일이므로 편집 모드·AI 작업·아웃라인·통계는 자동으로 비활성화됩니다.

### 체크박스 클릭 저장

`- [ ]` 목록은 **읽기 화면에서 바로 클릭**해 체크할 수 있고, 그 결과가 파일에 즉시 저장됩니다.
편집 모드로 들어갈 필요가 없습니다.

### 문서 수정일자 확인

상단 바 가운데의 **파일 이름에 마우스를 올리면** 툴팁으로 그 문서의 **전체 경로**와 함께
**생성 일시**, **수정 일시**가 나타납니다(예: `수정  2026-06-13 14:30`). AI나 다른 도구가
문서를 언제 마지막으로 고쳤는지 빠르게 확인할 때 유용합니다.

### 목차

상단 바의 **목차 아이콘**을 누르면 오른쪽에 제목 목록이 나옵니다. 항목을 클릭하면
그 위치로 이동하고, 스크롤하면 현재 위치가 자동으로 강조됩니다. 제목에 마우스를 올리면
북마크로 모아둘 수도 있습니다.

### 위키링크와 백링크

문서 안에 `[[파일이름]]` 또는 `[[파일이름#제목]]` 이라고 쓰면, 클릭 시 같은 폴더의 그 문서로
바로 이동합니다(제목까지 적으면 해당 위치로 스크롤). 찾는 문서가 없으면 "파일을 찾을 수
없습니다" 안내가 잠깐 뜹니다.

반대로, **지금 보는 문서를 `[[…]]`로 가리키는 다른 문서들**은 사이드바 아래쪽 **백링크**
목록에 모입니다. 가리키는 문서가 없으면 백링크 영역은 보이지 않습니다.

### 문서 통계 (토큰·단어·글자)

상단 바 파일 이름 옆에 **토큰 · 단어 · 글자 수**가 표시됩니다. 토큰은 GPT-4o·Claude 계열
기준으로 내 컴퓨터에서 계산하며, 파일을 연 직후 잠깐 뒤에 정확한 값으로 바뀝니다.

### 집중 모드

정독하거나 화면을 공유할 때 **집중 모드**를 켜면 상단 바와 사이드바가 사라지고 **본문만**
남습니다. `Ctrl+Shift+Enter`(macOS `⌘⇧Enter`), **보기 메뉴 → 집중 모드**, **문서 우클릭 →
집중 모드**, 또는 명령 팔레트(`Ctrl+K`)로 켜고, `Esc`로 해제합니다.

> [!tip] 문서를 열면 바로 키보드로 스크롤
> 문서를 열면 본문에 곧바로 포커스가 가므로, 마우스로 클릭하지 않아도 `↑`/`↓`·
> `Page Up`/`Page Down`·`Space` 키로 바로 스크롤할 수 있습니다.

### 읽은 위치 기억 · 맨 위로

- **읽은 위치 기억**: 긴 문서를 보다가 다른 문서로 갔다 와도, 또 **앱을 껐다 켠 뒤에도**
  마지막으로 보던 위치로 자동 복원됩니다. (별도 설정 없음)
- **맨 위로 버튼**: 아래로 충분히 내려가면 본문 **우하단에 ↑ 버튼**이 살짝 나타납니다.
  누르면 문서 맨 위로 부드럽게 돌아갑니다.

### 링크 · 확대/축소 · 테마

- 웹 링크(`http`)와 메일 링크는 클릭 시 **OS 기본 브라우저**에서 열립니다. 이런 **외부 링크에는
  작은 ↗ 표시**가 붙어 외부로 나가는 링크임을 알 수 있습니다. (문서 사이를 잇는 `[[위키링크]]`나
  같은 문서 안 이동 링크에는 붙지 않습니다.)
- 본문 글자 크기는 상단 바의 `-` / `%` / `+` 버튼, 단축키, 또는 `Ctrl`을 누른 채 마우스 휠로 조절합니다.
- **테마(라이트 / 다크 / 시스템)**는 **본문 우클릭 메뉴**, **설정**, 또는 **명령 팔레트(`Ctrl+K`)**에서 바꿉니다.

## 4. 빠르게 찾고 열기

여러 문서를 다룰 때 유용한 도구들입니다.

| 도구 | 단축키 | 설명 |
| --- | --- | --- |
| **명령 팔레트** | `Ctrl+K` | 거의 모든 기능(열기·새 문서·비교·검색·테마·집중 모드·변경 리뷰 등)을 이름으로 검색해 실행합니다. (`↑`/`↓` 이동, `Enter` 실행, `Esc` 닫기) |
| **최근** | — | 최근 연 파일·폴더. 시작 화면, 햄버거 메뉴, OS 메뉴의 `파일 → 최근 항목`에서 봅니다. |
| **즐겨찾기** | `Ctrl+D` | 자주 보는 파일·폴더를 사이드바 상단에 고정. 트리 항목이나 파일 이름 옆 **별표(☆)**로 추가하며, 드래그로 순서를 바꿀 수 있습니다. `Ctrl+D`는 **지금 보는 문서**를 즐겨찾기에 넣거나 뺍니다. |
| **빠른 열기** | `Ctrl+O` | 이름 일부만 입력해 문서·폴더를 바로 찾아 엽니다. **폴더 이름으로도 찾을 수 있어**, `SKILL.md`처럼 이름이 같은 파일이 많아도 폴더명(예: `ui-ux`)으로 구분해 엽니다(이런 파일은 **폴더 이름을 굵게** 표시). **폴더(📁)도 결과에 나오며 선택하면 그 폴더가 열립니다.** 헤더의 **`전체·폴더·파일`** 칸으로 검색 범위를 좁힐 수 있고(`Tab`으로 순환), 현재 폴더뿐 아니라 **`.claude` 스킬·즐겨찾기·최근의 파일/폴더**까지 함께 찾습니다. 입력이 비어 있으면 최근 파일을 먼저 보여 줍니다. (`↑`/`↓` 이동, `Enter` 열기, `Esc` 닫기) |
| **폴더 전체 검색** | `Ctrl+Shift+F` | 폴더 안 모든 문서의 **내용**에서 글자를 찾습니다. 결과를 클릭하면 그 파일이 열립니다. |
| **문서 내 검색** | `Ctrl+F` | 지금 열린 문서 안에서 글자를 찾습니다. 상단 바의 **검색 아이콘**으로도 엽니다. 검색창은 **다른 곳을 클릭하면 닫히고**, 보기↔편집 모드를 전환하면 자동으로 닫힙니다. |
| **편집 중 찾기·바꾸기** | `Ctrl+F` | 편집 모드에서 `Ctrl+F`를 누르면 **찾기·바꾸기** 막대가 열립니다. `Enter`/`Shift+Enter`로 다음·이전 이동, `Aa`로 대소문자 구분, **바꾸기**(현재 1개)·**모두 바꾸기**(`Shift+Enter`). 바꾼 내용은 실행 취소(`Ctrl+Z`)로 되돌릴 수 있습니다. |
| **컨텍스트 섹션** | — | 폴더를 열면 `CLAUDE.md`·`README.md` 등 안내 문서를 사이드바 맨 위에 자동으로 모아 줍니다(아래 5장 참고). |
| **스킬 섹션** | — | 폴더에 `.claude/`가 있으면 그 안의 **스킬·에이전트·커맨드**를 사이드바 "스킬" 섹션에 종류별로 모아 보여 줍니다. 항목을 클릭하면 해당 문서가 열리고, 파일을 추가·수정·삭제하면 목록이 자동으로 갱신됩니다. `.claude`가 없으면 섹션은 나타나지 않습니다. |

> [!tip] **빠른 열기**(`Ctrl+O`)와 **폴더 전체 검색**(`Ctrl+Shift+F`)은 단축키로 엽니다
> 이 두 도구는 별도 버튼 없이 **단축키로 호출**합니다. 폴더를 연 상태에서
> `Ctrl+O`를 누르면 파일 이름으로 바로 여는 창이, `Ctrl+Shift+F`를 누르면 폴더
> 전체 내용 검색 창이 뜹니다. (macOS는 `Ctrl` 대신 `⌘`)

> [!note] 폴더 전체 검색은 결과가 많으면 일부만 보여 줍니다
> 큰 폴더에서는 모든 결과를 다 띄우지 않고 일부만 표시합니다. 그럴 때는
> "결과가 많아 일부만 표시합니다"라는 안내가 보이며, 검색어를 더 구체적으로 입력하면 됩니다.

폴더 트리는 디스크 변경을 자동으로 반영합니다 — **새로 생긴 파일은 초록 점(●)**,
**수정된 파일은 호박색 점(●)**으로 표시되고, **삭제된 파일은 목록에서 사라집니다**.
그 파일을 열면 점은 사라집니다. 자동 반영이 안 될 때(특히 새 하위 폴더)는 탐색기 헤더의
**새로고침(↻)** 버튼이나 트리 영역 어디서나 **우클릭 → 탐색기 새로고침**으로 다시 읽으면 됩니다.

### 파일 이름 바꾸기 · 삭제

탐색기에서 파일·폴더를 **우클릭**하면 다음을 할 수 있습니다.

- **이름 바꾸기**: 그 자리에서 이름이 입력창으로 바뀝니다. 새 이름을 적고 `Enter`로 저장,
  `Esc`로 취소합니다. 같은 이름이 이미 있으면 덮어쓰지 않고 알려 줍니다. 이름을 바꾼 파일이
  즐겨찾기·최근 목록에 있거나 지금 열려 있어도 경로가 자동으로 따라갑니다(폴더는 그 안의 문서까지).
- **삭제**: 파일·폴더를 **시스템 휴지통으로 보냅니다**(완전 삭제가 아니므로 필요하면 OS 휴지통에서
  되돌릴 수 있습니다). 즐겨찾기·최근에서도 함께 정리되고, 지금 열려 있던 문서면 화면이 닫힙니다.

## 5. AI 작업에 유용한 기능

AI로 문서를 만들고 다듬을 때 특히 쓸모 있는 기능들입니다.

- **컨텍스트 섹션** — 폴더를 열면 `CLAUDE.md`, `AGENTS.md`, `SKILL.md`, `README.md`,
  `*.spec.md`, `plan*.md` 같은 **안내·설계 문서를 사이드바 맨 위에 자동으로 모아** 줍니다.
  AI에게 무엇을 시킬지 정의한 문서를 한눈에 찾을 수 있습니다. (모으는 파일 패턴은 설정에서
  바꿀 수 있고, 해당 문서가 하나도 없으면 이 섹션은 보이지 않습니다.)
- **합산 토큰 게이지** — 컨텍스트 섹션에서 문서 앞의 **체크박스를 1개 이상** 켜면, 사이드바
  아래에 선택한 문서들의 **합산 토큰**이 모델 한도(예: 128k / 200k / 1M) 대비 막대 그래프로
  표시됩니다. AI에게 한 번에 넣을 문서들이 한도를 넘는지 미리 가늠할 수 있습니다.
  (한도는 버튼이나 직접 입력으로 바꿀 수 있습니다.)
- **컨텍스트 → 프롬프트 복사** — 컨텍스트 섹션에서 문서를 체크한 뒤 합산 토큰 패널의
  **클립보드 아이콘**을 누르면, 선택한 문서들이 **파일 경계 머리말과 함께 하나의 텍스트로
  합쳐져 클립보드에 복사**됩니다(선택한 순서대로). AI에게 넣을 컨텍스트를 한 번에 모아
  붙여넣기 좋습니다.
- **AI 변경 리뷰 센터** — AI가 폴더 안 여러 문서를 고친 뒤, **무엇이 바뀌었는지 한 화면에서**
  검토합니다. 명령 팔레트(`Ctrl+K`)의 **변경 리뷰** 또는 사이드바의 **변경 N건 검토**로 열면,
  바뀐 파일 목록(생성/수정/삭제)과 함께 **내가 처음 본 내용 ↔ 현재 디스크 내용**의 줄 단위
  차이를 보여 줍니다. 다 확인했으면 **모두 확인**으로 표시를 한꺼번에 정리합니다.
- **위키링크 / 백링크** — `[[문서]]`로 관련 문서를 서로 연결해 두면, 클릭 한 번으로 오가고
  어떤 문서가 이 문서를 참조하는지(백링크) 바로 확인할 수 있습니다. 흩어진 설계 문서를
  엮어 두기 좋습니다.
- **두 문서 비교** — `Ctrl+\` 또는 햄버거 메뉴 → **다른 문서와 비교…**로 지금 문서와 다른
  문서를 **줄 단위로 비교**합니다(다른 문서에만 있는 줄=초록, 현재 문서에만=빨강). 프롬프트
  v1↔v2처럼 비슷한 두 문서의 차이를 볼 때 유용합니다. `Esc` 또는 ✕로 닫습니다.
- **AI 작업(검토 · 개선 · 요점정리 · 번역)** — 햄버거 메뉴·본문 우클릭의 **AI 작업**에서
  고를 수 있습니다. 모두 로컬에 설치된 `claude` CLI(Claude Code)를 통해 실행하므로
  **별도 API 키나 추가 과금 없이** 기존 Claude Code 로그인 그대로 사용합니다.
  - **검토** — 문서를 고치지 않고 문제점·개선점을 지적만 합니다(읽기 전용).
  - **개선** — 의미는 유지한 채 더 명확하게 다듬어 씁니다.
  - **요점정리** — 핵심만 짧게 요약합니다.
  - **한국어로 / 영어로 번역** — 문서를 번역합니다. 상단 바의 **번역 아이콘**에서도 바로 접근할
    수 있습니다.

  결과는 **원문 ↔ 결과 좌우 2-pane**으로 표시됩니다. 개선·번역 결과는 복사하거나 **새 파일로
  저장**할 수 있고(검토·요점정리는 저장 없이 복사만), 번역처럼 긴 문서를 청크로 나눠 처리하는
  작업은 진행 상황을 실시간으로 표시하며 **취소** 버튼으로 중단할 수 있습니다.

> [!note] AI 작업은 사용자가 직접 트리거할 때만 네트워크를 씁니다
> AI 작업 메뉴를 눌렀을 때만 `claude` CLI를 통해 Anthropic과 통신합니다.
> 그 외 모든 처리(토큰 계산·렌더링 등)는 네트워크 없이 로컬에서 이뤄집니다.

> [!tip] 모든 계산은 내 컴퓨터에서
> 토큰 수를 포함한 모든 처리는 로컬에서 이뤄지며 네트워크를 쓰지 않습니다
> (AI 작업 메뉴 제외 — 위 안내 참고).

## 6. 편집하기

MD좋아의 편집은 **오타 수정 수준의 간단 편집**입니다. 화려한 도구막대 없이 원본 Markdown을
그대로 고칩니다. 파일이 열려 있을 때 편집 모드를 켜면 됩니다.

- **줄 번호** — 편집 칸 왼쪽에 줄 번호가 표시됩니다. 긴 줄이 자동 줄바꿈돼도 번호는 논리 줄 기준으로 맞춰집니다.
- **분할 보기** — `Ctrl+E`로 편집 모드에 처음 진입하면 **편집 + 미리보기 분할 화면**이 기본으로
  열립니다. 입력하는 즉시 오른쪽 미리보기에 반영됩니다. 툴바의 **"편집만"** 버튼으로 단독 편집
  화면으로 전환할 수 있고, 다시 누르면 분할로 돌아옵니다.
- **실행 취소 / 다시 실행** — 여러 단계까지 됩니다(빠르게 연속으로 친 입력은 한 단계로 묶음).
- **자동 저장** — 입력을 잠시 멈추면 자동으로 저장됩니다(설정에서 끌 수 있음).
- **찾기·바꾸기** — `Ctrl+F`로 편집 칸 안에서 찾고 바꿉니다(`Enter`/`Shift+Enter` 다음·이전, `Aa` 대소문자 구분, **바꾸기**·**모두 바꾸기**). 모든 바꾸기는 실행 취소로 되돌릴 수 있습니다.
- **다른 이름으로 저장** — `Ctrl+Shift+S`(또는 햄버거 메뉴·명령 팔레트)로 지금 내용을 새 파일로 저장하고 그 문서로 전환합니다. 원본 파일은 그대로 둡니다.

> [!tip] 새 문서는 임시 파일로 시작합니다
> `Ctrl+N`으로 만든 새 문서는 이름 없이 바로 편집되며 입력 중에는 임시 파일에 자동저장됩니다.
> **저장(`Ctrl+S`)하거나 내용이 있는 채로 다른 문서로 넘어갈 때** 파일명·위치를 정하는 창이
> 뜹니다. 한 글자도 쓰지 않고 나가면 임시 파일은 조용히 정리됩니다.

> [!warning] 편집 중 외부 변경 — 내 편집은 절대 자동으로 사라지지 않습니다
> 내가 편집하는 동안 다른 도구(예: AI)가 같은 파일을 고쳤을 때:
> - **저장하지 않은 편집이 없으면** → 외부 변경 내용을 **편집기에 자동으로 반영**합니다.
> - **저장하지 않은 편집이 있으면** → 덮어쓰지 않고 "외부에서 변경됨 — 저장 시 내 편집으로
>   덮어씁니다" 경고와 **[디스크 내용 불러오기]** 버튼을 보여 줍니다. 직접 저장(`Ctrl+S`)하면
>   내 편집으로, [디스크 내용 불러오기]를 누르면 외부 내용으로 — 선택은 내가 합니다.
> - **파일이 외부에서 삭제되면** → "외부에서 삭제됨 — 저장하면 다시 생성됩니다" 안내가 뜨고
>   **편집 중인 내용은 그대로 보존**됩니다(`Ctrl+S`로 다시 만들기).

저장하지 않은 변경이 있는 상태에서 편집 모드를 끄거나 다른 파일을 열려고 하면, 변경을
잃지 않도록 먼저 확인 창이 뜹니다.

읽기 모드에서 파일이 외부에서 바뀌면, 설정의 **자동 새로고침**이 켜져 있을 때(기본값)는
자동으로 다시 읽고 "업데이트됨"을 잠깐 표시합니다. 꺼져 있으면 알림만 띄우니 **새로고침**
버튼으로 직접 갱신하면 됩니다. 보고 있던 문서가 **삭제되면** "삭제되었습니다 — 내용 보존 ·
[현재 내용으로 다시 저장]" 안내가 뜹니다(삭제된 파일이 다시 같은 이름으로 생기면 자동 복구).

## 7. 설정 · 내보내기

### 설정

햄버거 메뉴 → **설정**에서 조절합니다.

- **언어**(한국어 / 영어 / 시스템 자동 감지) — 바꾸는 즉시 메뉴바를 포함해 앱 전체에 반영됩니다.
- 변환 엔진(pandoc) 상태 확인·설치·삭제
- **파일 변경 시 자동 새로고침** 켜기/끄기
- **편집 중 자동 저장** 켜기/끄기
- **컨텍스트 문서 패턴** 편집(한 줄에 하나, `*` 와일드카드 가능 — 예: `*.spec.md`)
- 앱 정보 · 오픈소스 라이선스 보기

### 내보내기

상단 바의 **내보내기 아이콘**에서 제공합니다(문서가 열려 있을 때).

| 항목 | 설명 |
| --- | --- |
| PDF로 내보내기 | 인쇄 대화상자를 통해 PDF로 출력 |
| Word (DOCX) | DOCX로 변환(변환 엔진 pandoc 사용 — 없으면 설정에서 동의 시 1회 다운로드) |
| 서식 있는 HTML 복사 | 렌더링 서식을 유지한 채 클립보드로 복사 |

## 8. 단축키

> [!tip] Windows 기준으로 표기합니다
> 기본 표기는 **Windows**(`Ctrl`) 기준입니다. macOS에서는 `Ctrl` 대신 `⌘`(Command)
> 키를 사용하세요. 대부분은 OS 메뉴(`파일`·`보기`·`편집`)에도 함께 표시됩니다.

| 기능 | Windows | macOS |
| --- | --- | --- |
| 명령 팔레트 | `Ctrl+K` | `⌘K` |
| 새 문서 | `Ctrl+N` | `⌘N` |
| 파일 열기 | `Ctrl+O` | `⌘O` |
| 폴더 열기 | `Ctrl+Shift+O` | `⌘⇧O` |
| 빠른 열기 | `Ctrl+O` | `⌘O` |
| 뒤로 (문서 히스토리) | `Ctrl+[` 또는 `Ctrl+←` | `⌘[` 또는 `⌘←` |
| 앞으로 (문서 히스토리) | `Ctrl+]` 또는 `Ctrl+→` | `⌘]` 또는 `⌘→` |
| 다른 문서와 비교 | `Ctrl+\` | `⌘\` |
| 폴더 전체 검색 | `Ctrl+Shift+F` | `⌘⇧F` |
| 문서 내 검색 | `Ctrl+F` | `⌘F` |
| 사이드바 열기/닫기 | `Ctrl+B` | `⌘B` |
| 현재 문서 즐겨찾기 토글 | `Ctrl+D` | `⌘D` |
| 확대 | `Ctrl+=` 또는 `Ctrl++` | `⌘=` 또는 `⌘+` |
| 축소 | `Ctrl+-` | `⌘-` |
| 100%로 재설정 | `Ctrl+0` | `⌘0` |
| PDF로 인쇄/내보내기 | `Ctrl+P` | `⌘P` |
| 편집·보기 모드 전환 | `Ctrl+E` | `⌘E` |
| 집중 모드 켜기/끄기 | `Ctrl+Shift+Enter` | `⌘⇧Enter` |
| 저장 (편집 모드) | `Ctrl+S` | `⌘S` |
| 다른 이름으로 저장 | `Ctrl+Shift+S` | `⌘⇧S` |
| 찾기·바꾸기 (편집 모드) | `Ctrl+F` | `⌘F` |
| 실행 취소 (편집 모드) | `Ctrl+Z` | `⌘Z` |
| 다시 실행 (편집 모드) | `Ctrl+Shift+Z` / `Ctrl+Y` | `⌘⇧Z` / `⌘Y` |
| 설정 열기 | `Ctrl+,` | `⌘,` |

> [!note] `Ctrl+O`는 두 가지로 쓰입니다
> 폴더가 열려 있을 때 `Ctrl+O`는 **빠른 열기** 런처를 띄웁니다.

> [!note] 집중 모드 켜고 끄기
> **집중 모드**는 `Ctrl+Shift+Enter`(macOS `⌘⇧Enter`)·보기 메뉴·문서 우클릭·명령 팔레트로
> 켤 수 있고, `Esc`로 해제합니다.

## 9. 자주 묻는 질문

> [!note] 외부에서 파일을 고쳤는데 화면이 안 바뀌어요.
> 설정에서 **자동 새로고침**이 꺼져 있으면 알림만 뜹니다. 상단의 **새로고침** 버튼을 누르거나
> 설정에서 자동 새로고침을 켜세요.

> [!note] 체크박스를 클릭했더니 파일이 바뀌었어요.
> 의도된 동작입니다. 읽기 화면의 체크박스는 클릭하면 원본 파일에 바로 반영됩니다.

> [!note] 편집 중인데 자동 저장이 안 돼요.
> 다른 도구가 같은 파일을 고친 경우(외부 변경)에는 그 내용을 덮어쓰지 않으려고 자동 저장을
> 멈춥니다. 내용을 확인한 뒤 `Ctrl+S`로 직접 저장하세요.

> [!warning] 데이터는 밖으로 전송되지 않습니다.
> 토큰 계산을 포함한 모든 처리는 로컬에서 이뤄집니다. 네트워크를 사용하는 경우는
> 두 가지뿐입니다 — ① 사용자가 동의했을 때의 pandoc(변환 엔진) 다운로드,
> ② 사용자가 AI 작업 메뉴를 직접 눌렀을 때의 `claude` CLI 통신 (별도 과금 없음).
