# MD좋아 i18n(국제화) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MD좋아 UI를 한국어/영어 2개 언어로 전환 가능하게 만든다(OS 자동 감지 + 설정 수동 변경). 프론트 UI·네이티브 메뉴·사용자 매뉴얼·에러 메시지 전부.

**Architecture:** 신규 의존성 없는 경량 자체 사전(`src/lib/i18n/`). `ko.ts`/`en.ts` 중첩 사전 + `translate()` 순수 함수 + `t()`(비-훅)·`useT()`(훅). 언어는 기존 `theme` 패턴을 그대로 미러링해 `AppSettings.language: "system"|"ko"|"en"`로 저장. 네이티브 메뉴는 프론트가 라벨 객체를 Rust로 주입(사전 복제 없음). 완성 판정은 "사용자 노출 경로에 한글 리터럴 0"을 eslint 가드로 강제.

**Tech Stack:** Tauri 2.x + React 18 + TypeScript + Vite + Zustand. 테스트 vitest. 린트 eslint 10(flat config) + typescript-eslint. Rust(serde).

## Global Constraints

각 태스크의 요구사항에 아래가 암묵적으로 포함된다. 스펙에서 그대로 옮김.

- **신규 의존성 추가 금지.** i18n 라이브러리(i18next 등) 설치 안 함 — 자체 사전으로 해결. (CLAUDE.md 스택 유지 원칙)
- **네트워크/텔레메트리 금지.** 언어 리소스는 전부 로컬 정적.
- **단일 코드베이스로 Windows·macOS 동시 지원.** OS 분기는 `src/lib/platform.ts`(프론트), `#[cfg(target_os)]`(Rust)에만. 컴포넌트에서 `navigator.platform` 직접 검사 금지.
- **코드/경로 레벨은 ASCII만.** 파일명·식별자·키에 한글 금지. 표시명만 한글("MD좋아"는 제품 표시명이라 유지).
- **버전 일원화.** package.json / Cargo.toml / tauri.conf.json version 동일 유지(이번 작업은 버전 bump 불필요, 기존값 유지).
- **파일 I/O는 atomic write.** (이번 작업은 기존 `save_settings`의 tmp→rename 흐름 재사용, 신규 파일 쓰기 없음)
- **핵심 로직에 단위 테스트.** i18n `translate()`/`resolveLang`/보간/폴백/사전 완전성.
- **한국어 UI가 기본**(`language:"system"` → 한국어 로케일이면 ko). 영어는 사용자 선택 또는 영어 로케일에서.
- **단축키 모디파이어 추상화.** 메뉴 라벨의 단축키 힌트는 `platform.ts`의 `MOD_LABEL`(mac=⌘/win=Ctrl+) 사용.

```ts
import { describe, it, expect } from "vitest";
import { resolveLang, translate, interpolate } from "./index";
import { ko } from "./ko";
import { en } from "./en";

describe("resolveLang", () => {
  it("passes through explicit ko/en", () => {
    expect(resolveLang("ko")).toBe("ko");
    expect(resolveLang("en")).toBe("en");
  });
  it("'system' resolves via navigator.language", () => {
    // jsdom navigator.language is 'en-US' by default → en
    expect(resolveLang("system")).toBe("en");
  });
});

describe("interpolate", () => {
  it("replaces {name} tokens", () => {
    expect(interpolate("파일 열기 실패: {err}", { err: "X" })).toBe("파일 열기 실패: X");
  });
  it("leaves unknown tokens literal", () => {
    expect(interpolate("hi {who}", {})).toBe("hi {who}");
  });
  it("no params → unchanged", () => {
    expect(interpolate("plain")).toBe("plain");
  });
});

describe("translate", () => {
  it("looks up a dot-path key", () => {
    expect(translate("ko", "common.close")).toBe("닫기");
    expect(translate("en", "common.close")).toBe("Close");
  });
  it("interpolates params", () => {
    expect(translate("en", "toast.openFailed", { err: "boom" })).toBe("Failed to open file: boom");
  });
  it("missing key falls back to the raw key", () => {
    expect(translate("en", "nope.missing")).toBe("nope.missing");
  });
});

describe("dictionary parity", () => {
  // Compile-time guard is `const en: Dict`; this is the runtime belt-and-suspenders.
  const keys = (obj: any, prefix = ""): string[] =>
    Object.entries(obj).flatMap(([k, v]) =>
      typeof v === "object" && v !== null ? keys(v, `${prefix}${k}.`) : [`${prefix}${k}`]
    );
  it("en has exactly the same keys as ko", () => {
    expect(keys(en).sort()).toEqual(keys(ko).sort());
  });
});
```

- [ ] **Step 5: index.ts 작성 (코어 로직)**

`src/lib/i18n/index.ts`:
```ts
import { useAppStore } from "../../store/app";
import { ko } from "./ko";
import { en } from "./en";
import type { Dict } from "./ko";

export type Lang = "ko" | "en";
export type { Dict };

const DICTS: Record<Lang, Dict> = { ko, en };

/** "system" → OS 로케일(navigator.language) 기준. 그 외는 그대로. */
export function resolveLang(setting: string): Lang {
  if (setting === "ko" || setting === "en") return setting;
  const nav = typeof navigator !== "undefined" ? navigator.language : "en";
  return nav.startsWith("ko") ? "ko" : "en";
}

/** 점경로 키를 사전에서 조회. 미스면 ko로, 그것도 없으면 키 문자열(개발 중 가시). */
function lookup(lang: Lang, key: string): string {
  const walk = (root: unknown): string | null => {
    let cur: unknown = root;
    for (const p of key.split(".")) {
      if (cur && typeof cur === "object" && p in (cur as object)) {
        cur = (cur as Record<string, unknown>)[p];
      } else return null;
    }
    return typeof cur === "string" ? cur : null;
  };
  return walk(DICTS[lang]) ?? walk(DICTS.ko) ?? key;
}

export function interpolate(s: string, params?: Record<string, string | number>): string {
  if (!params) return s;
  return s.replace(/\{(\w+)\}/g, (_, k) => (k in params ? String(params[k]) : `{${k}}`));
}

export function translate(lang: Lang, key: string, params?: Record<string, string | number>): string {
  return interpolate(lookup(lang, key), params);
}

// 비-React 코드(스토어 액션/lib)용. 현재 언어를 스토어에서 지연 조회.
// ponytail: store↔i18n 순환 import는 함수 본문에서만 참조 → 모듈 평가 시점 충돌 없음(무해).
export function t(key: string, params?: Record<string, string | number>): string {
  const lang = resolveLang(useAppStore.getState().settings.language);
  return translate(lang, key, params);
}

// React 훅: 언어 변경 시 해당 컴포넌트를 리렌더한다.
export function useT() {
  const lang = useAppStore((s) => resolveLang(s.settings.language));
  return (key: string, params?: Record<string, string | number>) => translate(lang, key, params);
}
```

> 참고: `t()`/`useT()`는 `settings.language`를 참조하므로 Task 2에서 타입에 필드가 추가돼야 컴파일된다. Task 1의 테스트는 `translate`/`resolveLang`/`interpolate`만 호출하니 이 단계 테스트는 통과. `t`/`useT`가 참조하는 `settings.language`는 Task 2 완료 후 타입 통과.

```ts
import type { Lang } from "./i18n";
import { t } from "./i18n";

const MIN = 60_000, HOUR = 60 * MIN, DAY = 24 * HOUR, MONTH = 30 * DAY, YEAR = 365 * DAY;

// 수정시각 상대표시. <1분은 "방금 전 / just now", 그 외엔 Intl.RelativeTimeFormat로
// 영어 복수형을 자동 처리. ko는 접미사만 필요하나 동일 API로 일관 처리.
export function relativeTime(diffMs: number, lang: Lang): string {
  if (diffMs < MIN) return t("time.justNow");
  const rtf = new Intl.RelativeTimeFormat(lang, { numeric: "always" });
  const [unit, div]: [Intl.RelativeTimeFormatUnit, number] =
    diffMs < HOUR ? ["minute", MIN] :
    diffMs < DAY ? ["hour", HOUR] :
    diffMs < MONTH ? ["day", DAY] :
    diffMs < YEAR ? ["month", MONTH] : ["year", YEAR];
  return rtf.format(-Math.floor(diffMs / div), unit);
}
```

```ts
// Rust 에러 코드("code|arg1|arg2")를 현지화 메시지로. 미지 코드는 원문 그대로.
export function errorMessage(raw: string): string {
  const [code, ...args] = String(raw).split("|");
  const map: Record<string, string> = {
    file_too_large: "error.fileTooLarge",
    source_not_found: "error.sourceNotFound",
    name_exists: "error.nameExists",
    item_not_found: "error.itemNotFound",

  if (!key) return String(raw);
  // 위치 파라미터를 이름 파라미터로 매핑(코드별 순서 약속)
  const params: Record<string, string> =

}
```
